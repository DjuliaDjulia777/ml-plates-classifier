# Model_BPMN: Место ML-модели в бизнес-процессе

## 1. Описание бизнес-процесса
**Название процесса:** Контроль качества мытья посуды на предприятии общественного питания (или в клининговой компании).

**Цель процесса:** Обеспечить подачу клиентам только чистой посуды, минимизировать человеческий фактор и ускорить процесс приемки.

## 2. Роль ML-модели
Модель выступает в роли **автоматического контролера (инспектора)**. Она не заменяет мойщика посуды и не принимает окончательных решений об утилизации или повторном мытье, но она мгновенно сортирует поток посуды на «чистую» и «требующую внимания».

## 3. Пошаговое описание (BPMN-логика)

1. **Старт:** Посуда проходит через моечный цех.
2. **Задача:** Сотрудник или робот-манипулятор ставит тарелку под камеру на конвейере.
3. **Задача (ML):** Срабатывает камера. Изображение передается в ML-модель (`ML Plates Classifier`).
4. **Шлюз (Развилка):**
   - **Если модель предсказала `cleaned` (Уверенность > 95%):** Тарелка автоматически отправляется на полку для подачи клиентам.
   - **Если модель предсказала `dirty` (Или уверенность в `cleaned` < 95%):** Тарелка отправляется на повторное мытье или на визуальный контроль человеком.
5. **Конец:** Чистая посуда подана гостям. Процесс повторяется.

## 4. Схема процесса (PlantUML)

*Ниже представлен код схемы, который можно отрендерить на любом PlantUML-сервере (например, planttext.com).*

```plantuml
@startuml
skinparam ActivityBackgroundColor #E8F5E9
skinparam ActivityBorderColor #4CAF50

start
:Поступление грязной посуды;
:Подача тарелки под камеру;
:Получение изображения;
:Запуск ML-модели (ResNet-18);
if (Модель вернула 'cleaned'?) then (Да)
  if (Уверенность > 95%?) then (Да)
    :Тарелка признана чистой;
    :Отправка на полку;
  else (Нет)
    :Отправка на визуальный контроль;
  endif
else (Нет)
  :Тарелка признана грязной;
  :Отправка на повторное мытье;
endif
stop
@enduml
